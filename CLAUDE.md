# Trang Portfolio Site

## Project Purpose
Personal portfolio website for Trang Nguyen — showcases public health communication, research, and program work.

## Tech Stack
- Static HTML/CSS/JS (no build step)
- Password-gated via `js/auth.js` (client-side, session-based)
- Hosted on GitHub Pages: `https://trangnguyen1230.github.io/`

## Structure
- `index.html` — landing / about page
- `portfolio.html` — portfolio overview
- `contact.html` — contact page
- `public-health-comm.html`, `research-posters.html`, `patient-provider.html`, `program-policy.html` — project detail pages
- `css/` — stylesheets
- `js/auth.js` — password gate (runs before page renders)
- `images/` — site images

## Important Notes
- **Public repo** — do not commit secrets, credentials, or private career documents
- `profile.md` lives in the parent `trang-career/` repo, not here
